Читайте Новый Завет без рекламы, регистрации и лишнего шума. Только текст, спокойный свет и звуки природы, если хочется тишины вокруг.

## Что здесь есть

- **Четыре перевода** — русский (Кассиан), английский (NASB), армянский (Новый Арарат, 2018) и немецкий (Elberfelder 1905). Интерфейс тоже на четырёх языках.
- **Второй русский перевод** — Современный русский перевод (РБО): в русской версии переключается кнопкой рядом с выбором главы. В нём доступен и **Ветхий Завет** (39 книг): он появляется в списке книг при выборе РБО.
- **Удобное чтение** — книги и главы под рукой, избранные стихи, молитвы, предисловие для тех, кто открывает Писание впервые.
- **Звуки природы** — дождь, камин, хор, спокойное пианино, метель, а ещё ветер, птицы и гроза. Каждый раз звучат по-новому.
- **Свеча** — режим, при котором текст освещается тёплым кругом света, как при чтении в темноте.
- **Ваш вид** — несколько тем оформления, шрифты и размер текста на любой вкус.
- **Без интернета** — после первого открытия сайт работает офлайн.
- **Как приложение** — устанавливается на телефон и компьютер, отдельная иконка и никаких лишних панелей.

## Без интернета
Интерфейс сайта (страница, стили, скрипты, иконки) и основные шрифты сохраняет в кэш service worker при первом заходе. Тексты переводов и звуки подгружаются по мере чтения и тоже оседают в кэше. Чтобы сохранить всё заранее (переводы целиком, звуки, шрифты), в настройках есть вкладка **«Офлайн»**. Без интернета открывается последняя загруженная версия.

## Устройство и обновления
- Тексты лежат по книгам: `data/<перевод>/<книга>.js` (`cass`, `rbo`, `arar`, `nasb`, `elb`). Грузится только открытая книга, поиск догружает перевод целиком. Новый перевод: положить файлы в `data/<код>/` в том же формате (`(window.NTDATA=window.NTDATA||{});(NTDATA.<код>=NTDATA.<код>||{}).<книга>=...`).
- Звуки: `assets/audio/*.mp3`. Шрифты: Literata по умолчанию; остальные из выбора в настройках подгружаются, когда их выбирают (`FONT_GF` в `js/app.js`).
- **Автообновление.** `.github/workflows/pages.yml` при каждом коммите в `main` собирает сайт (`tools/build.js`: склеивает css в `css/app.css`) и запускает `tools/bump.js`. Он считает хеш файлов, вписывает его в `sw.js` (`BUILD`) и в `?v=` у css/js, пересобирает списки файлов для офлайна и размеры переводов. Поэтому после любой правки у посетителей подтягивается свежая версия: онлайн страница и тексты берутся из сети (кэш — запасной вариант), при открытой вкладке показывается кнопка «Обновить». Один раз нужно: Settings → Pages → Source: **GitHub Actions**.
- Без GitHub Actions (локально): `node tools/bump.js`. Списки файлов добавлять вручную не нужно.
- Приложение для Android: `app/vahik.apk` (ссылка в `js/install.js`, константа `APK`).

## Темы
Темы: blue-dark, dark-black, nardo-grey, warm-parchment, forest, bordeaux, dusk, ice, dark-sky (CSS-переменные в `css/base.css`, список — `themes` в `js/app.js`).
По умолчанию включена **тема по дням недели** (локальное время устройства): Пн — blue-dark, Вт — forest, Ср — dark-sky, Чт — nardo-grey, Пт — bordeaux, Сб — dusk, Вс — dark-black. Смена происходит в полночь без перезагрузки (таймер + проверка при возврате на вкладку), цвет меняется плавно, `meta theme-color` обновляется. Вместе с темой по дню меняется цвет заголовков и креста (`UIManager.HEAD`). Выбор темы или цвета заголовков вручную в настройках отключает авто-режим (тогда возвращается сохранённый цвет); переключатель «Тема по дням недели» включает его снова. Светлые темы для частиц и свечи: `warm-parchment`, `ice` (список в `ParticleEngine.loop` и в `css/base.css`).

## О переводе
Кнопка ⓘ рядом с названием перевода открывает окно с историей перевода: у каждого перевода свой текст на языке его локализации (Кассиан и РБО — ru, NASB — en, Նոր Արարատ — hy, Elberfelder — de). Тексты — в `js/translation-info.js` (неподтверждённые места помечены `TODO(автор)`), стили — в `css/translation-guide.css`. Вкладка «История» слева и предисловие при первом входе — в `js/reader.js` (`HIST`, `prefaceBody`); у каждой языковой версии они свои: история о том, как Писание пришло в страну этого языка, и вводная к Новому Завету.

### Обновление 2 (автосмена тем, облегчение, автообновление кэша)
