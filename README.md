# Vahik — Новый Завет

[vahe.app](https://vahe.app)

Веб-Сайт для внимательного чтения Нового Завета, размышления и молитвы.

## Возможности

- Четыре перевода: на русском, армянском, английском и немецком языках.
- Настройка шрифта, размера текста и цветовой темы.
- Личные заметки и сохранение избранных стихов.
- Звуки природы для спокойного чтения.
- Работа без интернета после первоначальной загрузки.
- Установка как веб-приложения и отдельный APK для Android.

## О проекте

Vahik — личный проект, который постепенно развивается. Его цель — сделать ежедневное обращение к Новому Завету доступным и удобным, сохранив внимание к самому тексту.

Замечания, предложения и сообщения об ошибках можно направить через [Telegram](https://t.me/vahe100).
